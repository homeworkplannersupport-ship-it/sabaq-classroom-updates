# Sabaq Workspace Build 8

Teachers can now create their own live classrooms from the Classroom hub. Firebase permanently blocks students and guardians from classroom creation and prevents a teacher from creating a classroom for somebody else.

Administrators can create managed student accounts with the student's email, age, and a temporary password. On first sign-in, Sabaq Workspace sends verification to that email. The student verifies ownership before entering the workspace and can replace the temporary password privately through Firebase password recovery.

The sign-in screen now remains stable while verification or missing-account errors are reported, and every password-entry field includes a safe eye button for showing or hiding only the text currently being typed. Firebase passwords are never stored or retrievable as readable text.

Following the confirmed full account reset, the approved owner can create and verify their email account to securely restore the first administrator. Other verified accounts proceed to Student, Teacher, or Guardian setup normally.
