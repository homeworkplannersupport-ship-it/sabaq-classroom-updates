# Sabaq Workspace — Build 6

Build 6 is the Mishkaat classroom workspace release.

- Verified cloud accounts with administrator, teacher, student, and guardian roles.
- Dedicated Stream, Classwork, People, and Grades areas for every classroom.
- Co-teachers, secure rosters, invitations, guardian links, and audited management.
- Rich assignments and announcements with multiple protected attachments, scheduling, editing, pinning, archiving, and discussion locks.
- Public class comments, private student–teacher comments, moderation, timestamps, and privacy-safe notifications.
- Optional per-class points, private grades, returned work, class summaries, and student/guardian grade views.
- Role-aware home activity stream, workload insights, reminders, submissions, feedback, and offline-readable cache.
- Complete Mishkaat-inspired interface, polished haptics and optional sounds, settings, version history, and one-time What’s New popup.
